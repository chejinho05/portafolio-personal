## Ejecución local

### Requisitos

- Node.js 20.9 o superior.
- npm.

### Instalación

```bash
npm install
```

### Desarrollo

```bash
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000) en el navegador.

### Compilación de producción

```bash
npm run build
npm run start
```
